# duhnunes.dev

Personal site of DuH Nunes. Next.js, Tailwind CSS and shadcn/ui.

```bash
pnpm install
pnpm dev
```

- `src/content/site.ts`: copy, projects and links (RDX first; only released projects).
- `src/lib/black-hole.ts`: the Canvas 2D black hole.
- `src/components/fall-hero.tsx`: scroll-linked fall into the hole.
- `src/components/project-card.tsx`: cards whose border is traced by a streak of light.

On Vercel, set the project's Root Directory to `web`.
